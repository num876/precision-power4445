# Precision & Power | Elite Landing Page Portfolio

A high-performance, premium portfolio designed to showcase landing page expertise.

## 🚀 Tech Stack
- **Core**: Vanilla JavaScript (ES6+)
- **Styling**: Vanilla CSS (Modern CSS Variables & Grid)
- **Advanced Interactivity**:
    - **Lenis**: Smooth momentum-based scrolling.
    - **Vanilla-tilt**: Interactive 3D card projections.
    - **Custom Cursor**: Magnetic, reactive LERP cursor system.
- **Vite**: Ultra-fast build tool and development server.

## 💎 Features
- **Dynamic Hero**: Floating parallax cards, focus glows, and animated background orbs.
- **Mobile Optimized**: Custom hamburger menu and touch-aware feature detection.
- **Glassmorphic UI**: High-end overlay systems and modal case studies.

## 🛠 To Edit in v0.dev
1.  **Import from GitHub**: Use the repository URL.
2.  **Edit**: v0 will recognize the `index.html`, `style.css`, and `main.js` structure.
3.  **Deploy**: Once edited, v0 can sync changes back to this repository and update your Vercel deployment.
